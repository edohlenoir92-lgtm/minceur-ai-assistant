# 🌿 Minceur AI Assistant

Backend IA pour le blog **Minceur au Fil des Saisons**.

## Fonctionnalités

- Génération de questionnaires
- Habitudes alimentaires
- Activité physique
- Objectifs minceur
- Préférences alimentaires
- Quiz nutrition
- Sondages
- Formulaires personnalisés

## Technologies

- Node.js
- Vercel
- Google Gemini API
- Blogger

## Endpoint

POST /api/generate

## Variable d'environnement

GEMINI_API_KEY

⚠️ La clé API Gemini ne doit jamais être publiée dans GitHub.
